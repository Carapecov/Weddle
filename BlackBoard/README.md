# BlackBoard

Diretório compartilhado de eventos e tarefas do Weddell Pay.

- `events.sqlite3`: armazenamento principal, criado no primeiro uso.
- `tasks/*.md`: resumos auditáveis gerados pelo servidor MCP.
- Consulte `../MCP_BlackBoard.md` para o fluxo entre agentes.

Não edite manualmente os snapshots `tasks/*.md`. Registre alterações pelas ferramentas MCP.
